Ovrule — decision receipts for AI agents

Every other guardrail reads what an agent says. Ovrule reads what the action does.

Top 7

of about fifty teams at Ship Season S26, presented live at Demo Day.

Situation
AI agents now run commands with real consequences, and most guardrails read what an agent says rather than what its action would do.
What I did
Built every layer alone — schema, classifier, evaluation set, API, interface, npm SDK. Six rules read each proposed action; a single failure refuses it.
Outcome
A live product and a published npm package. A refused action never runs, and every verdict leaves a signed receipt a compliance team can read.
